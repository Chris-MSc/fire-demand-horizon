# fire-demand-horizon

How far ahead can fire and rescue service demand be forecast?
Horizon-resolved forecast evaluation across incident types in England.

MSc Computer Science with Data Analytics, Northumbria University.

## Data sources

This repository contains code only. It does not redistribute either dataset;
the pipeline reproduces the analysis panel from the original public sources.

- **Incident data.** Fire statistics incident level datasets, England.
  Ministry of Housing, Communities and Local Government.
  Published under the Open Government Licence v3.0.

- **Weather data.** HadUK-Grid gridded climate observations, 1 km, v1.3.2.
  Met Office, via the Centre for Environmental Data Analysis.
  Registration required; see CEDA licence terms.
